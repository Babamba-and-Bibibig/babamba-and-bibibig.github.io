## 질문 1

이미지 5,000장으로 제품 불량 여부를 분류하는 모델을 학습시켰는데, 학습 데이터에서는 정확도가 매우 높지만 실제 새 이미지에서는 성능이 크게 떨어져요. 새로운 이미지를 추가로 촬영하기는 어려운 상황이에요. 어떤 방법을 시도해볼 건가요?

### 내 답변

과적합 현상이 일어나는 것으로 보인다. 학습한 이미지에 너무 맞춰져서 새로운 이미지에서는 제대로 분류하지 못하는 것 같다. 학습 이미지와 실제 이미지의 조명이나 촬영 각도가 많이 다른지도 확인해 봐야 할 것 같다.

추가 촬영이 어렵다면 데이터를 증강해서 다시 학습해 볼 것 같다. 같은 이미지를 조금 돌리거나 밝기를 조절하는 식으로 한 장에서 여러 변형을 만들어 학습에 사용하는 것이다. 실제로 촬영할 때 생길 수 있는 변화에 익숙해지도록 하는 데 도움이 될 것 같다.

다만 흑백으로 바꾸거나 필터를 넣는 것은 불량 여부를 판단하는 특징이 유지될 때만 해야 할 것 같다. 색의 차이가 불량의 단서라면 흑백으로 바꾸면서 그 정보가 사라질 수 있고, 필터 때문에 작은 흠집이 지워질 수도 있기 때문이다. 회전이나 밝기 조절도 이런 단서와 원래 정답이 유지되는 범위에서 적용해야 한다.

학습용과 검증용 이미지를 먼저 나누고, 증강은 학습용 이미지에만 적용해야 한다. 같은 원본에서 만든 이미지가 학습용과 검증용에 섞이지 않도록 하고, 별도로 남겨 둔 검증 이미지에서도 성능이 좋아졌는지 확인해 볼 것 같다.

## 질문 2

희귀 질환 여부를 판별하는 의료 이미지 300장으로 분류 모델을 처음부터 학습시키려 해요. 이 접근에는 어떤 문제가 있을까요? 어떤 대안을 제안할 건가요?

### 내 답변

300장이면 처음부터 이미지 분류 모델을 학습시키기에는 적어 보인다. 어떤 분류 모델인지와 이미지의 다양성에 따라 달라지겠지만, 학습해야 할 가중치가 많은 모델이라면 이 정도 데이터만으로 질환의 특징을 충분히 배우기 어려울 것 같다. 학습한 이미지만 잘 맞히고 다른 환자의 이미지에서는 제대로 분류하지 못하는 과적합도 생길 가능성이 높을 것 같다.

대안으로는 다른 데이터로 미리 학습된 모델을 가져와 사용하는 전이학습을 시도해 볼 것 같다. 이미지의 특징을 찾는 부분은 우선 그대로 두고, 마지막에 분류하는 부분을 질환 유무를 판별하도록 바꿔서 학습하는 것이다. 이미 학습된 특징을 활용하면서 새로 학습해야 할 가중치의 수를 줄일 수 있으므로, 모든 가중치를 처음부터 학습하는 것보다 데이터가 적은 상황에서 도움이 될 수 있을 것 같다.

다만 전이학습을 한다고 반드시 성능이 좋아지는 것은 아니므로, 학습에 사용하지 않은 이미지로 확인해야 한다. 같은 환자의 이미지가 여러 장 있다면 그 이미지들은 모두 학습용이나 검증용 중 한쪽에만 들어가도록 나눠야 할 것 같다.

## 02. 기존 모듈에 필요한 기능 하나가 없다면

> 날짜 데이터를 정리하는 기능이 필요해서 찾아보니, 이미 있는 모듈이 내가 원하는 기능의 대부분(요일 계산, 날짜 간격 계산)을 갖고 있어요. 그런데 딱 하나, 우리 회사만 쓰는 특이한 날짜 형식(예: '25년 3월 첫째 주')을 처리하는 기능만 빠져 있어요. 어떻게 할 건가요?

### 리서치 메모

<!-- 직접 검색하며 확인한 내용을 적습니다. -->
파이썬 날짜 모듈 커스텀이 가능한가? 

파이썬의 기본 datetime 모듈 자체를 직접 수정할 수는 없다.
단 상속을 통한 커스텀 클래스를 만들어서 구현이 가능하다. 
datetime.datetime을 상속받아 새로운 기능을 추가하거나 행동을 바꿀 수 있다.


pythonfrom datetime import datetime
class CustomDateTime(datetime):
    def to_kr_string(self):
        # 원하는 형식으로 커스텀 출력 메서드 추가
        return self.strftime("%Y년 %m월 %d일 %H시 %M분")

now = CustomDateTime.now()
print(now.to_kr_string())

## 03. PyTorch 모델을 클래스로 정의하는 이유

> PyTorch로 딥러닝 모델을 만들 때, 굳이 클래스로 모델을 정의하는 이유가 무엇일까요? 함수만으로 구현하는 방식과 비교해서 설명해 주세요.

### 리서치 메모

<!-- 직접 검색하며 확인한 내용을 적습니다. -->
클래스로 데이터를 표현해야 하는 이유

1. 데이터와 상태의 구조화: 이름, 나이, 연락처 등 서로 연관된 여러 변수를 하나의 사용자 정의 자료형으로 묶을 수 있습니다.
변수를 개별로 따로 관리할 때보다 코드가 단순해지고 가독성이 좋아집니다.

2. 코드의 재사용성과 확장성: 같은 구조의 데이터(인스턴스)를 여러 개 찍어내어 효율적으로 사용할 수 있습니다.
데이터뿐만 아니라 데이터와 관련된 기능(메서드)을 함께 정의하여 일관성 있게 다룰 수 있습니다.

3. 유지보수의 용이함: 데이터 형식을 수정해야 할 때 클래스 내부 정의만 바꾸면 되므로 전체 코드를 수정할 번거로움이 줄어듭니다.
실무에서는 데이터를 나르는 DTO나 데이터베이스 엔티티 형태로 널리 쓰입니다.


### 내 답변

<!-- 클래스로 정의하는 이유와 함수만으로 구현하는 방식의 비교를 직접 작성합니다. -->
저는 PyTorch로 딥러닝 모델을 클래스로 정의하는 이유를 이해하려면, 먼저 데이터와 그 데이터를 다루는 기능을 왜 함께 묶는지 생각해 볼 필요가 있다고 봅니다.
클래스를 사용하는 이유는 여러 가지가 있겠지만, 저는 관련된 데이터와 기능을 한곳에 모아서 관리할 수 있다는 점이 중요하다고 생각합니다. 
특히 데이터가 바뀌어야 할 때, 어떤 규칙에 따라 바뀌어야 하는지를 해당 기능과 함께 정리할 수 있다는 점이 장점이라고 봅니다.

모델에는 입력을 계산하는 과정뿐 아니라, 학습하면서 조정하는 가중치 같은 값도 필요합니다. 
모델에 등록한 가중치와 계산 과정을 한 객체 안에서 관리하고, 학습에 사용할 값들을 모아서 가져올 수 있습니다. 
단순히 클래스를 쓴다는 것뿐 아니라, PyTorch가 준비한 모델 관리 기능을 함께 활용하는 것입니다.

그래서 저는 클래스로 모델을 정의하는 이유가 “함수만으로는 만들 수 없어서”가 아니라, 
모델의 구성과 학습에 필요한 데이터를 함께 관리하기 편해서라고 생각합니다.



## 04. 100만 명의 고객 데이터를 처리하는 코드 개선

> 동료가 만든 코드가 파이썬 리스트와 반복문으로 100만 명의 고객 데이터를 처리하는데, 실행하는 데 몇 분씩 걸려요. 이 코드를 어떻게 바꾸면 좋을지 진단하고, 구체적인 개선 방법을 제안해 주세요.

### 리서치 메모

NumPy 라이브러리로 반복문 사용하기
import numpy as np

arr = np.array([1, 2, 3, 4])
for x in arr:
    print(x)
    
### 내 답변

<!-- 문제에 대한 진단과 구체적인 개선 방법을 본인의 언어로 작성합니다. -->

실제 업무라면 AI에게 도움을 요청할 수도 있겠지만, 그 전에 반복문이 왜 필요한지와 어떤 계산을 반복하고 있는지부터 이해하려고 할 것 같습니다.

우선 같은 계산을 불필요하게 반복하고 있지는 않은지 살펴볼 것 같습니다. 예를 들어 모든 고객에게 똑같이 적용되는 값을 매번 다시 계산하고 있다면, 반복문 밖에서 한 번만 계산하도록 바꿀 수 있을 것입니다. 
또한 조건에 맞는 고객만 추가 처리가 필요한 상황이라면, 해당 조건을 먼저 확인해서 나머지 고객에게는 불필요한 계산을 하지 않도록 할 것 같습니다. 

그리고 큰 데이터를 다루기 위해 만들어진 라이브러리인 NumPy를 사용하는 방법도 살펴볼 것 같습니다. 
NumPy의 배열 연산을 활용하면 최적화된 내부 계산을 편리하게 사용할 수 있기 때문에, 만약 NumPy를 쓸 수 있는지도 한번 생각해 볼 것 같습니다.

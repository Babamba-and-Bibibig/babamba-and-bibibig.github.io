## 질문 1

모델이 학습 데이터에서는 정확도 99%, 테스트 데이터에서는 70%가 나왔어요. 편향과 분산 중 어느 쪽 문제일까요? L1·L2 규제는 이 문제를 어떻게 줄이나요?

### 1) 구글링 리서치 메모

#### 1. 편향(Bias)과 분산(Variance)의 작동 원리 {#research-bias-variance .research-topic}

모델의 전체 예측 오차는 편향² + 분산 + 노이즈(제거 불가 오차)로 구성됩니다.

- **편향(Bias):** 모델이 학습 데이터를 얼마나 정확하게 반영하는지 나타냅니다.
  - **원리:** 모델이 너무 단순하면(예: 복잡한 곡선 데이터를 직선으로 예측) 데이터의 본질적인 관계를 학습하지 못해 실제값과 예측값의 차이(편향)가 커집니다. 이를 과소적합(Underfitting)이라고 합니다.
- **분산(Variance):** 서로 다른 학습 데이터를 주었을 때 모델의 예측이 얼마나 요동치는지(변동성)를 나타냅니다.
  - **원리:** 모델이 너무 복잡하면(예: 고차 다항식이나 깊은 신경망) 데이터의 무작위 노이즈까지 전부 외워버립니다. 학습 데이터는 완벽하게 맞추지만, 새로운 데이터가 들어오면 예측값이 완전히 튀어버리는 과적합(Overfitting)이 발생합니다.

#### 2. 편향-분산 트레이드오프(Trade-off) {#research-tradeoff .research-topic}

모델의 복잡도를 높이면 편향은 줄어들지만 분산이 커지고, 반대로 복잡도를 낮추면 분산은 줄어들지만 편향이 커집니다. 모델 학습의 목표는 이 둘의 합이 최소가 되는 최적의 균형점을 찾는 것입니다.

### 2) 내 답변

학습 데이터에서는 99% 정확도이지만 테스트 데이터에서는 70%인 것은 과적합 현상인 것 같습니다.
과적합은 편향보단 분산에 대한 문제입니다.

따라서 분산을 줄여야 하는데 이때 분산을 줄이는 방법으로 L1, L2 규제가 자주 쓰인다고 배웠습니다. 모델의 복잡도가 커질수록 문제 현상에 대해서 이해도가 높아집니다. 다만 이 복잡도가 데이터에 너무 밀착되어서 학습이 되면 과적합 현상이 일어납니다. 그래서 L1, L2 규제가 모델의 복잡도를 조금 낮추는 대신 과적합 현상을 줄어들게 해주는데, 이렇게 되면 모델의 복잡도가 줄어들어서 데이터의 디테일한 변화를 감지하지 못할 수 있어서 정확도가 떨어지는 트레이드오프 현상이 일어납니다.

규제의 원리는, 손실 함수에 고의로 페널티 항을 더해서 학습을 조금씩 방해합니다. 모델은 무조건적으로 가중치를 올릴 수 없고 이 페널티 항까지 고려하면서 최적의 가중치 값을 다시 찾아야 합니다. 이런 식으로 분산 현상을 줄이는 것으로 알고 있습니다.

## 질문 2

랜덤 포레스트와 그레이디언트 부스팅은 둘 다 결정 트리 여러 개를 합친 모델이에요. 두 모델은 트리를 만들고 합치는 방식이 어떻게 다른가요? 트리 개수를 계속 늘리면 각 모델에 어떤 일이 생길지도 예상해 주세요.

### 1) 구글링 리서치 메모

#### 1. 결합 방식의 핵심 차이 {#research-ensemble-comparison .research-topic}

| 구분 | 랜덤 포레스트(Random Forest) | 부스팅(Boosting) |
| --- | --- | --- |
| 앙상블 유형 | 배깅(Bagging): Bootstrap + Aggregation | 순차적 부스팅(Boosting) |
| 트리 생성 순서 | 독립적(병렬로 동시에 여러 트리 생성) | 순차적(이전 트리의 오차를 보완하며 다음 트리 생성) |
| 학습 데이터 | 복원 추출(Bootstrap)을 통한 서로 다른 샘플 + 무작위 특성(Feature) 선택 | 이전 모델이 틀린(오차가 큰) 데이터에 가중치를 높여서 학습 |
| 결과 결합 방식 | 다수결 투표(분류) 또는 평균(회귀) | 각 트리의 예측값을 가중치를 더해 합산 |
| 주된 목적 | 분산(Variance) 감소(과적합 방지, 안정성 향상) | 편향(Bias) 감소(예측 오차를 줄여 높은 정확도 추구) |

#### 2. 상세 비교 {#research-ensemble-details .research-topic}

##### ① 랜덤 포레스트(배깅 기반) {.research-detail}

- **작동 방식:** 원본 데이터에서 복원 추출한 여러 개의 서브샘플로 서로 독립적인 결정 트리들을 동시에 만듭니다. 각 분할 노드에서도 모든 특성이 아닌 무작위로 일부 특성만 골라 트리를 다양하게 만듭니다.
- **결합 방법:** 모든 트리가 내놓은 결과를 취합하여 분류는 다수결, 회귀는 평균을 취해 최종 결정을 내립니다.
- **장점:** 개별 트리의 노이즈나 과적합(Overfitting) 위험이 낮고, 병렬 처리가 쉬우며 하이퍼파라미터 튜닝이 비교적 쉽습니다.

##### ② 부스팅(부스팅 기반) {.research-detail}

- **작동 방식:** 첫 번째 트리를 만든 뒤, 그 트리가 잘 맞추지 못한 데이터(오차)에 더 큰 가중치를 줍니다. 두 번째 트리는 이 가중치 높은 오차를 집중적으로 학습하며, 이 과정을 순차적으로 반복합니다(예: Gradient Descent 활용).
- **결합 방법:** 생성된 순서대로 트리의 예측값에 가중치를 부여해 최종 예측을 누적하여 도출합니다.
- **장점:** 랜덤 포레스트보다 일반적으로 더 높은 예측 정확도를 보여주며, 복잡한 데이터 패턴을 잘 학습합니다.
- **단점:** 트리를 순차적으로 만들어야 하므로 병렬 처리가 어렵고 학습 시간이 오래 걸리며, 노이즈 데이터에 과적합될 위험이 상대적으로 높습니다.

#### 트리를 늘렸을 때 {#research-number-of-trees .research-topic}

##### 1. 배깅(Bagging)과 병렬 결합 {.research-detail}

배깅(대표적으로 랜덤 포레스트)은 여러 트리를 독립적으로 학습시킨 뒤 평균(또는 다수결)을 내는 병렬 결합 방식입니다.

- **과적합(Overfitting) 위험이 없습니다.** 트리의 개수를 무한히 늘려도 모델이 복잡해져서 발생하는 과적합은 일어나지 않습니다.
- **분산(Variance)이 감소하며 에러가 특정 하한선으로 수렴합니다.** 트리가 추가될수록 개별 트리의 무작위성(노이즈)이 상쇄되어 예측이 안정해집니다. 일정 개수 이상이 되면 더 이상 성능이 좋아지지도, 나빠지지도 않는 포화 상태가 됩니다.
- **컴퓨팅 비용만 증가합니다.** 성능은 정체되는데 메모리 사용량과 연산 시간만 불필요하게 늘어납니다.

##### 2. 부스팅(Boosting)과 순차 결합 {.research-detail}

부스팅(대표적으로 Gradient Boosting, XGBoost, LightGBM)은 이전 트리의 오차를 다음 트리가 보완하는 순차 결합 방식입니다.

- **과적합(Overfitting) 위험이 매우 높습니다.** 트리의 개수를 계속 늘리면 모델이 훈련 데이터의 아주 미세한 노이즈와 아웃라이어(이상치)까지 모두 학습해 버립니다.
- **편향(Bias)이 극도로 낮아지지만, 분산(Variance)이 커집니다.** 데이터의 패턴을 완벽하게 외우는 수준에 이르러, 훈련 데이터에 대한 오차는 0에 가까워지지만 새로운 데이터(테스트 데이터)에 대한 예측 성능은 처참하게 떨어집니다.
- **이를 막기 위해 조기 종료(Early Stopping)가 필수적입니다.** 검증 데이터의 손실이 더 이상 줄어들지 않을 때 트리가 더 추가되지 않도록 제어해야 합니다.

### 2) 내 답변

랜덤 포레스트는 결정 트리 여러 개를 병렬로 돌려서 결괏값을 가지고 평균을 내서 사용하는 방식이고, 부스팅은 결정 트리를 순차적으로 결합해서 이전 모델의 오차를 보완하여 학습하는 방식입니다.
랜덤 포레스트는 여러 개의 결괏값에서 평균을 사용해서 고르기 때문에 트리가 많아져도 과적합에 어느 정도 내성이 있을 것 같습니다. 다만 부스팅 모델은 잔차를 바로바로 이어서 다시 학습하여 보완하기 때문에 좀 더 직접적으로 학습을 할 것 같습니다. 다만 트리를 늘리게 되면 학습 데이터를 과하게 학습하여 과적합이 랜덤 포레스트보다 상대적으로 더 쉽게 일어날 것 같습니다.
